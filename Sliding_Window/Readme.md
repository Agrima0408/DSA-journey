# 🪟 Sliding Window

A powerful optimization technique used for solving problems involving **contiguous subarrays** and **substrings** in **O(n)** time.

---

## 📚 Topics Covered

- Fixed Size Window
- Variable Size Window
- Longest Window Problems
- Smallest Window Problems
- Frequency Based Window
- At Most K
- Exactly K
- Sliding Window + HashMap
