# 🌳 Trees

> *"At first, trees look confusing. Then one day recursion clicks... and suddenly everything starts making sense."* 🌿

Trees are one of the most important data structures in DSA. They are used in databases, file systems, compilers, search engines, operating systems, and countless interview problems.

Unlike arrays or linked lists, trees are **non-linear**, meaning each node can branch into multiple paths.

## 🧠 Concepts to Remember

### 🌿 Basic Terminology
- Root
- Parent
- Child
- Sibling
- Leaf Node
- Internal Node
- Ancestor
- Descendant

---

### 📏 Important Properties

- Every tree has exactly one **Root**.
- Every node (except the root) has exactly one **Parent**.
- A **Leaf Node** has no children.
- Trees contain **no cycles**.
- A Binary Tree can have **at most two children** per node.
